# 読む時間を、少し豊かに

朝の静かな時間に、昨日書いた文章を読み返す。文字の大きさと行間を整えるだけで、見慣れた言葉が違って見えることがある。

## 見た目のサンプル

普通の文章と **太字**、*斜体*、~~取り消し線~~、==ハイライト==。

> 大切なことは、読み進めるうちに自然と目に入る。

### 今日のメモ

- 気になった文章を保存する
- 見出しを付けて整理する
  - 話題ごとに分ける
- 好みのテーマで読み返す

1. 「テーマ・表示設定」を開く
2. `ink.theme.css` を選ぶ
3. 必要なら本文や見出しを調整する

- [x] 読むための準備
- [ ] 次の一冊を選ぶ

| 要素 | 設定例 |
| --- | --- |
| 本文 | 18px / Yu Mincho |
| 見出し | 28px / Yu Gothic UI |

```text
SattoMDV.exe "reading.md"
```
